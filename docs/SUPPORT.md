# Support

- **Bugs and feature requests:** open a GitHub issue in this
  repository. For a kit, name the kit in the title and include
  the kit version (or commit), your Windows version, and the
  smallest reproduction you can manage.
- **Questions about using a kit or tool:** GitHub issues are
  fine for these too; check the kit's own README and
  [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) first.
- **Security problems:** do not use public issues — follow
  [`SECURITY.md`](SECURITY.md) (private vulnerability
  reporting).

Support is best-effort by a single maintainer, without
response-time guarantees.
