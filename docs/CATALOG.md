# The Windows DLL Collection — Catalog

## TL;DR

34 small Windows DLLs that each do one common job — watching folders, making thumbnails, showing notifications, handling settings — so programs do not have to reinvent them. Every kit is free (MIT) and ships as a ready-to-use download from this repository's Releases: the DLL, a C header, and an import library. Any programming language that can call C functions can use them.

## How every kit works

- Plain C interface (a header file is included), so C, C++, C#, Rust, Python,
  PowerShell and anything else with a C-calling feature can use them.
- Settings and results travel as JSON text — no structs to line up.
- Errors come back as readable text, never as a crash.
- No Rust crate dependencies: each kit builds from its own source in this
  repository. Two kits use native engines, named in their rows below
  (OCRKit vendors its OCR engine; EmbedKit loads a user-supplied ONNX Runtime).
- Built from Rust with the full test suite in the repository; the whole
  collection is gated by one CI workflow in this repository.

Every kit in this repository was field-verified on a real Windows machine on 2026-10-28 (smoke pack plus manual demos, pre-monorepo builds). The monorepo builds below are CI-verified; their field re-checks are recorded per kit in docs/AUDIT.md as they happen (OCRKit's monorepo build was field-verified on 2026-11-01).

Downloads are x64 and unsigned (there is no code-signing certificate);
Windows may show a SmartScreen prompt on first use. Every download page
also carries a `SHA256SUMS.txt` — check your download against it.

This file is generated by `tools/catalog.py` from `docs/CATALOG_DATA.json` and each kit's `Cargo.toml`. Do not edit it by hand; run `python tools/catalog.py generate`.
