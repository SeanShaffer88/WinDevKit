# Code of Conduct

Be decent to work with. This project is a shared workshop, and
everyone helping here — maintainers, contributors, and people
filing issues — is expected to:

- Be respectful and constructive, especially in disagreement.
- Criticize code and ideas, not people.
- Keep discussions on the work; no harassment, insults, or
  personal attacks.
- Assume good faith until given clear reason not to.

The maintainer may moderate, close, or remove contributions or
comments that break these expectations, and may block repeat
offenders. Report a problem through a GitHub issue marked for
the maintainer, or privately via the security advisory route in
[`SECURITY.md`](SECURITY.md) if it is sensitive.
