# Windows DLL collection — consumer index

Checked October 22, 2026. **13 projects: 12 DLL/native-build projects and one Rust-only shared crate.** This is a scoped source/metadata index, not a claim of equal maturity or universal Windows compatibility. Meridian is excluded. Exact source commits, headers, requirements and pilot digests are in [the JSON index](DLL_COLLECTION.json).

## Packaged pilot

[FastSearch v0.1.0-preview.1 — Windows x64](https://github.com/SeanShaffer88/FastSearch/releases/tag/v0.1.0-preview.1) contains the DLL, MSVC import library, header, C/Python examples, MIT license, build provenance and verification scripts. The public ZIP was downloaded again and its SHA-256 verified. Native C and Python clients ran against the packaged build on Windows 11 Home build 26300 x64. It is unsigned; clean-host, ARM64/x86 and broad platform acceptance remain unverified.

Read its [consumer guide](https://github.com/SeanShaffer88/FastSearch/blob/main/docs/CONSUMER_GUIDE.md) for runtime prerequisites and memory/threading rules. No other row is advertised as a validated binary release from this pilot. CI artifacts can expire.

## Engine and license boundaries

- **OCRKit:** engine-less success does not prove OCR. Real OCR needs pinned Tesseract/Leptonica support code and separately supplied language data; preserve their licenses.
- **Whisper:** engine-less success does not prove transcription. Recognition needs pinned whisper.cpp/ggml and a separately supplied ggml model; preserve upstream and model terms.
- **EmbedKit:** the vector index is separate from model inference. Compatible ONNX Runtime, model and vocabulary files and their terms remain the consumer responsibility.
- **SQLiteSuperBuild:** the build-script license does not replace upstream SQLite and vec-extension notices. Its interface is the upstream SQLite ABI.
- **WinCommon:** a Rust implementation crate, not another DLL. Reviewed scaffold integration exists; adoption by existing DLLs is a separate step.

Sean-owned source is MIT-licensed unless the actual source says otherwise. Retain each shipped component copyright, license and generated-data notices. This index grants no redistribution rights for external engines, models, runtimes or Windows components. None is bundled here.

## Consumer release checklist

1. Match process architecture, header and exact source/build manifest. Keep engine-enabled and engine-less artifacts distinct.
2. Use the allocating DLL matching free function exactly once for owned results. Never free static/error pointers or use another component deallocator. Headers override general conventions.
3. Copy thread-local errors immediately; coordinate callbacks, handles and DLL unloading. Do not infer thread safety across projects.
4. Validate real C/C#/Python consumption, malformed inputs, failure/cancellation cleanup, runtime dependencies and permissions. Compile checks are not native acceptance.
5. Ship versioned assets with source provenance, architecture, license notices, SHA-256 and gaps. Checksums alone do not authenticate a publisher.
6. Read update, archive, image and recovery trust/input limits. None is a general sandbox or recovery certification.

No dependency was adopted and no engine/model downloaded for this index. Non-pilot projects were not all rebuilt here; each row states its validation scope.
