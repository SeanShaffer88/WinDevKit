# Examples

Worked examples of the tools and kits in use. Each one is complete
and runnable on Windows.

## SettingsKit in five minutes

SettingsKit is the collection's flagship: atomic JSON settings files
with schema versioning and migrations. Both examples do the same
job — open a settings file, set two values, save, read one back —
so you can compare the two calling styles.

- [`settingskit-csharp/`](settingskit-csharp/) — a C# program whose
  binding (`SettingsKit.cs`) was generated by BridgeKit from the
  kit's shipped header, plus a hand-written `Program.cs` that uses
  it. Build it with any .NET 6+ SDK (`dotnet run` with a minimal
  project file, or drop both files into a console project).
- [`settingskit-python/`](settingskit-python/) — the same flow from
  Python using only the standard library's `ctypes`, showing the
  caller-owned string rule by hand.

You need `settings_kit.dll` next to the program in both cases:
download `SettingsKit-0.1.0-x64.zip` from this repository's
[Releases](https://github.com/SeanShaffer88/WinDevKit/releases),
check it against the release's `SHA256SUMS.txt`, and unzip.
